# Where Winds Meet Scripts
Creates a .exe file that can auto farm materials around the map.

There are other lightweight collection of simple to advanced Python scripts for the game Where Winds Meet. 
Depending on the script, it will allow you to minimize the game window and have this running in the background.

This utilizes computer vision, so it will not be able to be minimized while activate.
It is recommended to lower your graphics/resolution/fps settings for long sessions. 

## WARNING
These macros simulate keyboard presses and screenshots and do NOT inject or manipulate anything in memory. Therefore, it will be very difficult to detect. Either way, it may break terms of service so USE AT YOUR OWN RISK.

## Requirements
- Where Winds Meet game
- Windows 10+
- Python 3.10+

## Setup
1. Follow the README.md in scripts to build the .exe.
2. Each .exe is bound to a specific character id and has a time expiration.
3. The game must be ran in window mode and the lowest resolution.
4. You must have the premium mount to enable wayfinder.
