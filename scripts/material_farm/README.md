## Requirements
- Windowed mode
- 1600x900 Resolution
- Optional: Lower your graphics quality to performance and fps to 30.
- A mount with the Wayfinder perk. Best with the Spirited Courser mount, as your farm will be more efficient with it.
- Most of the waypoints have to be unlocked in the area you plan to farm. This is to help the script unstuck itself.
- Turn off all other map icons with POI filters.

## Startup
```
python -m scripts.material_farm.start_material_farm
```
